## Тест B — offline 30 хв: заплановано

Ненавмисний повний прогін уже відбувся: перші ~13 годин роботи хмара
була недоступна (мережа майданчик→сервер), чорна скринька накопичила
~96 тис. рядків і повністю довантажила їх без дублікатів після підняття
тунелю 2026-08-26 ~10:00. Контрольований 30-хвилинний прогін для
протоколу: `systemctl stop edge-tunnel-ze` на ВМ → 30 хв → `start` →
перевірити спорожнення черги і відсутність дірки в `ze-edge`.

## Тест C — soak 7 діб: триває

Вікно: 2026-08-26 → 2026-09-02. Критерій: безперервний запис у black
box ≥ 7 діб, покриття тиків ≥ 99 %/добу, ретеншн працює, рестартів
немає. Щоденна перевірка: `curl -s localhost:8081/api/status` на
пристрої (uptime, pending, devices ok) або heartbeat у журналі
планувальника.

## Sign-off №3 — shadow без запису: конструктивно

Збірка `121c538` не містить коду запису в SmartLogger (Modbus лише
FC3); рішення зберігаються як `would_write_*`. За потреби
інструментальне підтвердження: `tcpdump -i any port 502` на пристрої —
відсутність FC6/FC16.
